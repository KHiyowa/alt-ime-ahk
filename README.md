# Alt-IME 2

## 概要

USキーボードで、左右 Alt キーの空打ちの挙動を無変換キー・変換キーに変更する AutoHotkey スクリプトです。  

* 左 Alt キーの空打ちで「無変換」キーを送信
* 右 Alt キーの空打ちで「変換」キーを送信
* Alt キーを押している間に他のキーを打つと通常の Alt キーとして動作
  * ただし、Shift キーとの同時押しは「Shift + 無変換/変換」として動作（ATOKのショートカット活用が可能）
* Alt キーを素早く2回連打すると通常の Alt キー（メニュー呼び出し等）として動作

## 動作環境

* Windows 11

Windows 10でもおそらく動きますが、環境がないため動作保証対象外です。  
特定のIMEに依存せず動作します。

## 使い方

Releasesから alt-ime-ahk.zip をダウンロードして展開し、 alt-ime-ahk.exe を任意の場所に置いて実行してください。    
終了する場合はタスクトレイのアイコンを右クリックし、「Exit」をクリックしてください。  
アンインストールは alt-ime-ahk.exe を削除するだけで OK です。  

無変換キー・変換キーの挙動はご利用のIME側で設定してお使いください。  
無変換キーをIME OFF・変換キーをIME ONに設定すると、オリジナルの alt-ime-ahk と同じ挙動になります。

## オリジナルからの変更点

* **AutoHotkey v2.0 対応**: v2.0 の仕様に合わせてコードを完全にリライトしました。
* **シンプル化**: 外部ライブラリ (IME.ahk) への依存を排除し、単一ファイルで動作するようにしました。
* **IME制御方式の変更**: IMEのAPIを直接操作するのではなく、OS標準の「変換(vk1C)」「無変換(vk1D)」の仮想キーコードを送信する方式に変更しました。これにより、IME側でのキーカスタマイズが有効になります。
* **キーフックの採用**: `A_PriorKey` を使用することで、大量のキー定義を廃止し、シンプルかつ軽量な実装に変更しました。
* **Electron系アプリ対策**: Alt空打ち時のメニュー抑制キーを `vk07` から `vkE8` に変更し、送信方式を `SendInput` にすることで、VS Code や Discord 等での挙動を安定させました。
* **Altキー連打機能**: 200ms以内にAltキーを2回連打することで、通常のAltキー（メニュー呼び出し等）として動作する機能を追加しました。
* **専用キーボード対応**: 大宮技研製「英数・かなキーボード」に対応しました。

## 英数・かなキーボードの使用

英数・かなキーボードを使用する場合は、Windows向けのファームウェアを書き込む必要があります。
